# Projeto-Agrinho2026
Este site foi desenvolvimento como parte do Projeto Agrinho, com o objetivo de apresentar a importância e as características do agro no sudoeste do Paraná, destacando a agricultura, a sustentabilidade, a preservação e as tecnologias utilizadas no campo de forma criativa e interativa.

O projeto tambem serve como prática de programação web utilizando linguagens HTML, CSS e JavaScript.

# Funcionalidade
- Layout moderno e responsivo;
- Galeria de imagens do Agro;
- Cards informativos;
- Navegação suave;
- Menu de acessibilidade;
- Efeitos visuais;
- Quiz interativo.
